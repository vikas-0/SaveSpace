# Changelog

All notable changes to SaveSpace will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release of SaveSpace
- Browse Live Photos from Photos library
- Filter by album and date
- Bulk selection of photos
- Space savings estimation
- Convert Live Photos to standard photos
- Preserve Long Exposure effects and key frame selection
- Preserve all metadata (date, location, favorite status)
- Export video clips (.MOV) before conversion
- Export original Live Photos before conversion
- Batch conversion with minimal permission prompts
- Modern SwiftUI interface
- App icon

### Technical
- MVVM architecture with SwiftUI
- Actor-based services for thread safety
- PhotoKit integration for photo library access
- Async/await throughout for modern concurrency
